Scans

One row per Source (a folder scans/<ip>/), one column per Scan Profile. A cell turns ✓ when the Scan it expects is in the folder. Click a cell to download the script to run on that Source. Drop nmap files (.xml, .gnmap, .nmap) on a row to store them for that Source. Excluding a Scan moves it to excluded/: it is kept, not read.
