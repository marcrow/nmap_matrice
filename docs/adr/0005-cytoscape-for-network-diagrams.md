# Network diagrams are drawn with Cytoscape.js, not Mermaid

The report's network diagrams (per Source first, then the others) are drawn by Cytoscape.js with layouts written for SegOWL (Zones as compound frames placed around or beside the Source), instead of Mermaid flowcharts. Mermaid's layered layouts (dagre, ELK) turn a Source reaching 40 Interfaces into one very tall column or one squashed row, stretch the Zone frames, and Mermaid 10's ELK renderer drops the edge and frame colours that carry the Flow Policy. Cytoscape (MIT, about 0.8 MB inlined against 3.3 MB for Mermaid) keeps `report.html` offline, condenses the same data into one screen, and adds hover, drag and Zone hiding. It costs our own layout code, PNG-only export (no maintained non-GPL SVG export; the user judged PNG enough), and a look to redesign. Evaluation: `.scratch/report-readability/graph-library.md` and the POC on branch `prototype/report-readability` (`prototype_report/cytoscape_poc/`).
