# The local app runs on the Python standard library, no web framework

The web app (`segowl serve <mission_dir>`) is built on `http.server.ThreadingHTTPServer`, `ssl` and `hashlib.scrypt`, with server-rendered HTML and a little plain JS, rather than Flask or FastAPI. SegOWL runs on offline client sites and from a plain checkout with zero dependencies; a framework would have to be vendored or installed offline, for a handful of concurrent auditors at most. Authentication is a `users` file of `login:scrypt-hash` lines written by `segowl user add`; without it the server only binds `127.0.0.1`. Concurrent edits are guarded optimistically (a save is refused if the file changed since it was loaded) instead of locks. Revisit if the app ever needs to serve a large team or many missions at once.
