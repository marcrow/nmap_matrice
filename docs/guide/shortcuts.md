# Shortcuts

Every editor saves as you go.

## Everywhere

| Keys | Effect |
|---|---|
| ++ctrl+z++ | Undo, every change of the page until it is reloaded (also the bar at the bottom left) |
| ++ctrl+y++ / ++ctrl+shift+z++ | Redo |

## Inventory

| Gesture | Effect |
|---|---|
| Paste (++ctrl+v++) | Paste rows straight from the client's spreadsheet |
| Select cells, then type | Fill every selected cell with what you type (suggestions from the column) |
| ++ctrl+d++ | Fill down: copy the first row of the selection into the others |
| Rename a Machine | Offers **Rename everywhere**: its other Interfaces and the Flow Policy follow |

## Scans: build the scan

| Keys | Effect |
|---|---|
| ++arrow-up++ / ++arrow-down++, ++enter++ or ++tab++ | Pick a result in the port search |
| Type in the command line | Add a port, `top 1000`, an option or an NSE script; ✕ removes |
| ++backspace++ in an empty command field | Remove the last token |
| ++esc++ | Close the suggestions |

## Flow Policy

| Gesture | Effect |
|---|---|
| Click, or ++enter++ / ++space++ | Open a cell to decide |
| Arrows | Move between cells |
| ++shift++ + click | Select a rectangle |
| ++ctrl++ + click | Pick scattered cells, or a Zone header for its row or column |
| ++ctrl+c++ / ++ctrl+v++ | Copy a decision to the selection, as `ports;action;comment` text that travels between Missions |
| ++del++ | Empty the selected cells |
| ++esc++ | Close the cell |
